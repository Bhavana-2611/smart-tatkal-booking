# 🚆 Smart Tatkal Booking System

Smart Tatkal Booking System is a Flask-based web application designed to simulate and simplify the Tatkal ticket booking process. The system allows users to register, log in, search for trains, check seat availability, and book Tatkal tickets efficiently.

---

## 🌟 Features

- 🔐 User Registration & Login
- 👤 Secure Session Management
- 🚆 Train Search Functionality
- 🪑 Seat Availability Display
- 🎟️ Tatkal Ticket Booking Simulation
- 📄 Booking Confirmation Page
- 🔓 Logout Feature

---

## 🛠️ Tech Stack

- **Backend:** Python (Flask)
- **Frontend:** HTML, CSS
- **Database:** SQLite
- **Template Engine:** Jinja2

## ⚙️ Installation Guide

### 1️⃣ Clone the Repository

```
git clone https://github.com/your-username/SmartTatkalBooking.git
cd SmartTatkalBooking
```

### 2️⃣ Install Required Packages

```
pip install -r requirements.txt
```

### 3️⃣ Run the Application

```
python app.py
```

### 4️⃣ Open in Browser

Visit:

```
http://127.0.0.1:5000/
```

## 🔄 How It Works

1. User registers and logs into the system.
2. User searches for available trains.
3. System displays seat availability.
4. User selects Tatkal booking option.
5. Booking confirmation is generated.
